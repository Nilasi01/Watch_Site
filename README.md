# 🕰️ Watch Store Website

A modern, responsive **Watch Store landing page** showcasing elegant watch collections with smooth animations, Swiper sliders, and interactive sections. Built using **HTML, CSS, and JavaScript**.

---

## 🌟 Features

- 🏠 **Responsive Design** — Works perfectly on desktop, tablet, and mobile.  
- ✨ **Modern UI/UX** — Stylish layout with consistent spacing and typography.  
- 📸 **Image Highlights** — Featured, Story, and New Arrival sections.  
- 💬 **Client Testimonials** — Swiper.js slider for customer feedback.  
- 🧭 **Animated Scroll Effects** — Implemented using ScrollReveal.js.  
- 🛒 **Interactive Navigation** — Hamburger menu for mobile view.  
- 📩 **Newsletter Subscription** — Simple call-to-action section.

---

watch-store/

## ⚙️ Technologies Used

- **HTML5** – Semantic structure and content
- **CSS3** – Flexbox, Grid, and media queries
- **JavaScript (ES6)** – DOM manipulation & ScrollReveal integration
- **Swiper.js** – Image and testimonial slider
- **Remix Icons** – Modern icon set
